# Аварийный откат и удаление

Инструкция выдаётся **до установки и испытаний**. Выполняйте команды через SSH по локальному подключению к роутеру. Интернет для этих действий не нужен. Не закрывайте рабочую SSH-сессию во время испытаний.

Имена пакетов: `mwan3-autobalancer` и `luci-app-mwan3-autobalancer`. Имя службы: `mwan3-autobalancer`. Эти имена обязательны для реализации и установки.

## Быстро вернуть штатную балансировку

```sh
/etc/init.d/mwan3-autobalancer disable
ubus call service delete '{"name":"mwan3-autobalancer"}'
/etc/init.d/mwan3 restart
```

Первая команда исключает автозапуск контроллера. Вторая останавливает все его экземпляры через штатный procd, без запуска Go-программы. Третья пересоздаёт обычные правила из текущей `/etc/config/mwan3`. Контроллер не должен записывать в этот файл рассчитанные веса. WAN могут потребовать около минуты на повторную проверку доступности.

Если контроллер ещё не установлен, отсутствие его init-script или службы ожидаемо; последнюю команду всё равно можно выполнить. Эти команды не исправляют проблему оператора, SIM-карты или USB-кабеля.

## Полностью удалить

Сначала выполните быстрый откат выше. Затем:

```sh
opkg remove luci-app-mwan3-autobalancer mwan3-autobalancer
/etc/init.d/mwan3 restart
/etc/init.d/rpcd restart
```

Это удаляет UI и контроллер. Не используйте `--autoremove`: существующие сетевые пакеты должны остаться на месте. Не удаляйте `mwan3`, `firewall`, `dnsmasq` и не сбрасывайте роутер в заводские настройки ради удаления контроллера.

## Проверить результат

```sh
mwan3 status
ping -c 3 1.1.1.1
```

Если каналы online, но сайты не открываются, дополнительно:

```sh
nslookup example.com
ip -4 route
```

Ping проверяет лишь выбранный маршрут; успешный ответ не доказывает работоспособность всех WAN или DNS. Возврат штатных правил подтверждается чтением политики `balanced` в `mwan3 status`.

## Если SSH-соединение потеряно

Подключитесь к локальной сети роутера снова, предпочтительно Ethernet-кабелем. Войти по LAN можно и при отсутствии WAN-интернета, если LAN/Wi-Fi и SSH продолжают работать. Проект не должен менять их настройки. Если контроллер выключен и runtime-правила удалены, перезагрузка заново загружает штатные правила mwan3; сначала выполняйте аварийное отключение, чтобы контроллер не запустился снова.

## Граница защиты

Обычный crash процесса не перепрошивает устройство. Возможные последствия дефекта root-программы — нарушение маршрутизации, расход трафика, CPU/RAM или места для логов. Контроллер ограничивает эти действия, запускается в наблюдении и имеет независимое восстановление, но его безопасность подтверждается тестами перед включением управления.
